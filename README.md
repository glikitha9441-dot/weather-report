# SkyCast — Weather Report

A responsive weather report website built with HTML, CSS, and JavaScript. It displays current weather conditions and a five-day forecast for a searched city.

## Features
- Search weather by city
- Current temperature and weather conditions
- Humidity, wind speed, feels-like temperature, and rain chance
- Five-day forecast
- Responsive design for phones and computers
- Live weather from the free [Open-Meteo API](https://open-meteo.com/)

## Run the project
1. Open `index.html` in a browser, or enable GitHub Pages in the repository settings.
2. Search for a city such as Kurnool, Hyderabad, or Bengaluru.
3. An internet connection is required for live weather data.

## Technologies
HTML5 · CSS3 · JavaScript Fetch API · Open-Meteo Geocoding and Forecast APIs

## Note
This is an educational project, not an emergency weather-warning service.
